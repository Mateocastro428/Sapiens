Cada lección sigue el mismo recorrido: primero los hechos, luego las causas, después el análisis y finalmente el debate. Un método diseñado por historiadores para construir pensamiento crítico de forma progresiva.

La fase de mayor reto intelectual. Se te presenta un enunciado polémico y debes construir una respuesta argumentada usando lo que aprendiste. No hay una sola respuesta correcta: se evalúa la solidez del razonamiento.
